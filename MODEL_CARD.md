# LuwiAI-V1 Small — model card

## Summary

LuwiAI-V1 Small is a **from-random-initialization, byte-level decoder-only Transformer** trained by this project on a narrow corpus generated by project-authored deterministic templates. It is a real trained neural language model artifact, but it is an experimental toy-scale checkpoint—not a general-purpose assistant, frontier model, or autonomous agent.

## Artifact and reproducibility

- Checkpoint: `runs/local_cpu_v2/checkpoint.pt`
- SHA-256: `4c15e08d69fa421111d867d231b2e10e56f4ba11ec92964992d58fb262913af6`
- Architecture: 3 Transformer encoder blocks with causal attention mask; `d_model=96`, 4 attention heads, context 192 bytes; tied byte embedding/output weights.
- Parameter count: 403,296.
- Training: PyTorch, CPU, random initialization, 2,500 optimizer steps, AdamW, batch size 8, seed 314159.
- Training split: 10,800 generated examples; held-out validation split: 1,200 examples; generator seed 7.
- Data: only locally generated arithmetic/string instruction templates authored in this repository; no pretrained weights, external corpus, or benchmark questions included.
- Objective: answer-byte causal loss conditioned on each complete user prompt.
- Validation answer loss at final logged training step: approximately 1.05 (sampled validation batches; not a standardized metric).
- Held-out exact match: 7/100 (7%) on a random sample using evaluator seed 42. This diagnostic is limited to this generator and is not an external benchmark.
- Automated tests: 10 passed in the development environment.

## Intended use

Use for educational inspection of a small Transformer, byte-level autoregressive training, provenance tracking, and pipeline experimentation. Do not use as a reliable assistant, coding model, knowledge model, or unsupervised autonomous agent.

## Limitations

- Very small model and training budget; extremely limited task/content coverage.
- Low exact-answer accuracy even on its own simple generated tasks; output may be malformed or incorrect.
- No image, audio, video, retrieval, long-context, or software-engineering capabilities.
- No agent planning or tool-use training. The separate guarded calculator runtime is a prototype utility, not model capability.
- No ARC-AGI-3, SWE-Bench, MMLU-Pro, or other external benchmark evaluation. No 100% score, first-to-market, or state-of-the-art claim is supported.
- Procedural generation and provenance checks are not legal certification that future model outputs cannot resemble protected material.

## Safety and governance

The tool runtime has an explicit calculator allowlist and rejects arbitrary code. It does not provide process/container isolation and should not be treated as a deployment security boundary. External data additions require separate rights, privacy, security, and quality review under `DATA_POLICY.md`.
